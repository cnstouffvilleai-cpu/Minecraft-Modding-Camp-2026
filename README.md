**HOW TO DOWNLOAD YOUR KID'S MOD**

1. Click on the zip file with your kid's name
2. Click the download icon in the top right corner

**HOW TO GET MCREATOR**

1. Go to https://mcreator.net/download
2. Download the newest version
3. Run the installer

**HOW TO IMPORT THE MOD INTO MCREATOR**

1. Open MCreator
2. Click "Import from file"
3. Select the zip file you downloaded
